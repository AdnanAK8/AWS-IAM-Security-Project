# AWS-IAM-Security-Project
AWS IAM and Account Security project demonstrating users, groups, roles, and policy management in AWS.
## Objective
To learn AWS Identity and Access Management (IAM) and understand how access to AWS resources is controlled.

## Concepts Covered
- IAM Users
- IAM Groups
- IAM Roles
- IAM Policies

## Steps Performed
1. Created IAM User
2. Created IAM Group
3. Assigned Policies
4. Created IAM Role
5. Tested Permissions

## Outcome
Successfully learned how AWS IAM helps secure cloud resources by controlling access and permissions.
